# Backend Development & Database Integration

A PHP + MySQL based authentication system with complete CRUD functionality.

## Features
- User Registration
- Password Strength Validation
- Login Authentication
- Session Handling
- Dashboard
- Profile Management
- Update Profile
- Delete Account
- Logout System

## Technologies Used
- PHP
- MySQL
- XAMPP
- HTML
- CSS
- GitHub

## How to Run

1. Start Apache and MySQL in XAMPP
2. Open phpMyAdmin
3. Create database: apexdb
4. Import/create users table
5. Run:

http://localhost/task_3
